# QR Code Generator

A simple and responsive QR Code Generator built with **React.js** and the `react-qr-code` library.
Enter any text, URL, or value into the input field and generate a QR code instantly.

## 🚀 Features

- Generate QR codes from any text or value
- Simple and clean user interface
- Generate button is disabled when the input is empty
- QR code updates dynamically

## 🛠️ Technologies Used
- React.js
- JavaScript
- CSS
- `react-qr-code`
